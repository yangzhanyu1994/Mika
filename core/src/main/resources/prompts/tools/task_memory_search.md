Look up summaries of past tasks (across conversations) so you can reuse what worked and avoid repeating what failed. Returns up to 10 compact entries — only the title, when it ran, which apps/sites it touched, its one-line conclusion and step count, never the full steps. Query with words from the task title, its conclusion or its steps; filter by app package and/or a start date when you know them. When a returned entry looks relevant, read its timeline with task_memory_timeline and then a specific step with task_memory_step.
