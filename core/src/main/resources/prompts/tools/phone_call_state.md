Read native cellular call state, the local AI call feature's readiness, and available SIM ids. default_outgoing_sim_id is the user's saved outgoing SIM and default_outgoing_sim_available indicates whether it is currently available. If it is available, use it without asking the user to choose a SIM again, unless they explicitly request another one. If the saved SIM is unavailable, ask for a new choice; never substitute another SIM silently. A dialing or connecting state is not a completed call. API credentials and transcripts are not returned. The call_id identifies the unique current call and is required for answering or hanging up that call.
