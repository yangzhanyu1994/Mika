Read the phone's current location from the system location service. The result includes coordinates, accuracy in meters, age in milliseconds, collection time, and whether the fix is cached. place is present only when the on-device geocoder returned a label; if geocoder is none or unavailable, there is no place and you must not invent one. failure is no_permission, services_off, auto_off, needs_background, or no_fix. Do not describe a failed or cached reading as a live position. Do not send these coordinates yourself. A weather request uses read_weather, which sends coordinates only to Open-Meteo when location is authorized, or geocodes a city the user named. Without a grant, do not read the phone location.
