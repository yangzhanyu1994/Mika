Read the phone's current location from the system location service. The result includes coordinates, accuracy in meters, age in milliseconds, collection time, and whether the fix is cached. place is present only when the on-device geocoder returned a label; if geocoder is none or unavailable, there is no place and you must not invent one. failure is no_permission, services_off, auto_off, needs_background, or no_fix. Do not describe a failed or cached reading as a live position, and do not send the coordinates to any other service.
