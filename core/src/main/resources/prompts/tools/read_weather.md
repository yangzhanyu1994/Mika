Read weather from the Open-Meteo public API. Pass city only when the user named a place; that does not read the phone location. Omit city only when location is already authorized; that one request sends the coordinates to Open-Meteo and nowhere else. Do not read location without a grant. The result includes source, observation time, timezone, and fetch time. failure is network, no_location, no_permission, services_off, auto_off, needs_background, no_fix, unknown_city, or incomplete. Do not invent a temperature, place, or time when ok is false. An unknown weather code has no condition phrase. Coordinates and the place name are omitted from the run log.
