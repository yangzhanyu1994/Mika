Read weather from the Open-Meteo public API. Pass city only when the user named a place. Omit city to use the authorized device location; coordinates are sent only to that weather service. The result includes source, observation time, timezone, and fetch time. failure is network, no_location, no_permission, services_off, auto_off, needs_background, no_fix, unknown_city, or incomplete. Do not invent a temperature, place, or time when ok is false. An unknown weather code has no condition phrase.
