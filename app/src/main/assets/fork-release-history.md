### 近期版本更新说明

#### [v0.2.12](https://github.com/yangzhanyu1994/Mika/releases/tag/v0.2.12) · 2026-11-20

- 豆包朗读接入官方语音合成 2.0，使用该服务的 API Key。试听可取消，超时会显示提示。
- 简化声音模型设置，把任务语音和自定义服务商配置收进高级设置并补充说明。
- 首页使用听筒图标。通话缺少麦克风权限时可直接申请，拒绝后可跳到系统应用权限设置。
- 已授权时，通话会等到 Mika 回到前台并收到录音数据后才显示接通。读不到麦克风、音频焦点失败和豆包连接失败时分别提示，可直接重试。
