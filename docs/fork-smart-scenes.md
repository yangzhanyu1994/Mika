# 智能场景（第一阶段）

在侧栏进入智能场景。现有定时任务保留原入口，也可从场景页进入。蓝牙场景可选择已配对设备、连接或断开事件、等待秒数和执行内容。默认等待 60 秒；等待期间状态反转时取消该次触发。场景通过现有任务调度与通知机制执行，上次执行入口打开对应对话，并不代表任务已经成功。

启用场景需要允许附近设备访问；监听使用前台服务和常驻通知。系统蓝牙关闭、权限撤销、用户完全退出、系统停止服务或设备重启后未能恢复服务时，场景不能保证触发。重新打开 Mika 会尝试恢复监听。系统电池策略、精确闹钟权限和后台限制也可能影响执行时效，需要在真实设备上验证。监听停止期间的事件不会补发。Wi-Fi 和位置仅显示为后续支持，不执行监听。

车辆检查应由用户在任务内容中明确要求读取并报告状态；无法读取或确认的情况应在结果中说明，不能假设车辆已上锁或车窗已关闭。操作其他 App 还取决于设备解锁、无障碍权限和目标 App 的实际状态。
