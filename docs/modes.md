# 询问与自主

简体中文 | [English](modes.en.md)

Mika 替你办事时，有两种模式决定哪些步骤要先问你。全局一个开关：设置里的「开发者选项」→「自主模式」，关着是询问，打开是自主。

| 模式 | 行为 |
|---|---|
| **询问**（默认） | 只有花钱的那一步先问你：下单、提交订单，或者页面上显示着应付金额时的确认、提交。卡片上写明在哪、买什么、多少钱，只能同意这一次或不同意。付款本身由你亲手完成。发消息、发帖、提交表单、删除、改设置这些都不问，直接做完。 |
| **自主** | 连付款也不先问你，直接做完。成批做事时两次之间的间隔照样保留。 |

- 换了开关管之后的所有任务；正在做的任务从询问换成自主，下一步起付款也不再问。
- 登录、验证码、付款密码这类要你亲手处理的事，两种模式都会请你接管；信息不够、或者只有你能选（比如两个同名联系人选哪个）时，也会问你。
- 定时任务等你不在场的任务，在询问模式下遇到要花钱的一步不会等人，会直接不做，并照实告诉你哪一步没做成；别的照常做完。
- **降低风控**（设置里的开关，默认开）另算一层，询问和自主都生效：每一步之间随机停几秒（默认大约 3–15 秒，可改最小和最大，不按固定节拍）；每个 App 有每小时、每天的次数，到了就停下并通知你。屏幕上出现「操作频繁」、滑块、拼图或人脸验证时马上停下、通知你，并把这个 App 暂停 24 小时，不会去通过验证。微信、小红书、淘宝、闲鱼、京东里的发送、发布、评论、点赞、关注、下单、付款、改价，以及闲鱼的擦亮，都要你先确认；没人确认就不做。淘宝、闲鱼、京东还会限制搜索、翻页和打开详情，小红书的浏览次数更少。关掉开关后，这些额外限制不再加上。

你同意的动作，以及自主模式下 Mika 替你做的动作，都由你负责。重要的事请用询问模式，并检查结果，见[免责声明](disclaimer.md)。
