# Fork: 来电交代与聊天入口

2026-11-13：根据用户对 v0.1.44 的真机反馈，普通聊天增加来电任务的读取、按编号修改和删除；执行前检查已有任务，相同内容的重复保存会复用正在生效的记录。旧任务不会自动删除。主要聊天入口的来电任务管理委派给后台任务；侧栏中文名称调整为“主要聊天”和“新建旁聊”。

通话提示要求先根据对方表述区分快递与外卖，身份不确定时询问；自称身份不构成认证。角色识别依赖实时语音模型，必须在实际来电中验证，不能视作可靠的身份认证或保证转告成功。模型收尾失败时，只在有保存成功回执时提示曾保存，并要求核对现有任务。

测试结果和实际发布状态见本次 PR 及 CI；三星设备上需验证角色询问、重复任务、保存后收尾失败以及更新保留数据。一次转告后自动结束及可靠的已转告状态尚未实现，不根据对话摘要自动判定完成。

2026-11-13：按用户要求，通话记录按记录的处理状态区分待处理/已处理，摘要中的待办独立保留；侧栏提示未处理记录和可用更新，并在无更新时显示当前版本。已有来电交代可在编辑页转为永久，普通编辑保留原有绝对截止时间。具体测试及发布状态见对应 PR 和 CI；实际三星设备体验仍需验证。

2026-11-13：拨出设置增加默认拨号卡和独立的拨出开场白；已有接听开场白保持不变。多卡且未设置默认时仍需选择，已保存的卡不可用时不自动替换；允许本次显式选择另一张。拨出任务使用主动说明来意的语音规则，不复用接听的通用应答；涉及敏感内容时先核对对象。语音模型何时主动接续、对方实际听到什么，以及双卡选择的设备表现均需真机验证，不应仅凭接通状态宣称已转告或已完成。
